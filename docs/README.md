# Formation IA Togo - Plateforme Interactive

🌍 **Séminaire Intelligence Artificielle pour Entrepreneurs Togolais**

## 📖 À propos

Cette plateforme interactive accompagne la formation IA Togo, un séminaire intensif de 5 jours destiné aux entrepreneurs togolais souhaitant utiliser l'Intelligence Artificielle pour développer leur business.

## ✨ Fonctionnalités

### 🎯 Interactives
- ✅ **Suivi de progression** - Cochez les modules complétés, sauvegarde automatique locale
- 📊 **Barre de progrès en temps réel** - Visualisez votre avancement instantanément
- 🎮 **Quiz interactif** - Testez vos connaissances avec feedback immédiat
- 🌓 **Mode sombre/clair** - Confort de lecture adapté à vos préférences
- 📱 **Responsive** - Fonctionne sur mobile, tablette et desktop

### 📚 Contenu
- **Programme complet 5 jours** - 20 modules, 35 heures de formation
- **5 Cas d'étude business** - Exemples concrets d'entreprises togolaises
- **Outils IA gratuits** - Liste complète des ressources recommandées
- **Ressources téléchargeables** - Guides, annexes, exercices
- **Certificat de participation** - Débloqué à 100% de complétion
