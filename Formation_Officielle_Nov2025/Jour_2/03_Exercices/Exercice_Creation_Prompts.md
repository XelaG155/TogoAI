## 🏋️ EXERCICE 1 : TRANSFORMER UN PROMPT BASIQUE

### Étape 1: Prompt basique (❌ Mauvais exemple)

**Testez ce prompt dans ChatGPT:**

```
Écris un email pour un client mécontent.
```

**Question:** Quel résultat obtenez-vous? Est-il utilisable directement?

### Étape 2: Prompt amélioré avec structure

**Maintenant testez ce prompt optimisé:**

```
**PERSONA:**
Tu es un responsable service client d'une entreprise de logistique au Togo,
réputée pour son professionnalisme et son sens du service.

**TÂCHE:**
Rédige un email de réponse à un client mécontent dont le colis n'est pas
arrivé à la date promise.

**CONTEXTE:**
- Le client: M. Kouamé, directeur commercial, attend ce colis depuis 5 jours
- Raison du retard: problème douanier indépendant de notre volonté
- Le colis sera livré demain matin
- C'est la première fois que nous avons un problème avec ce client

**FORMAT:**
- Ton: professionnel mais chaleureux
- Longueur: 150-200 mots
- Structure: 1) Excuses, 2) Explication, 3) Solution, 4) Geste commercial
- Langue: français professionnel

**CONTRAINTES:**
- Ne pas blâmer les douanes directement
- Proposer un geste commercial concret (ex: 10% réduction prochaine commande)
- Terminer sur une note positive
```

**Question:** Comparez les deux résultats. Quelles différences notez-vous?

### Test A/B de vos prompts

**Pour chacun de vos 3 prompts:**

1. **Testez avec ChatGPT**

   - Notez votre satisfaction /10

## 💡 BONNES PRATIQUES APPRISES

### ✅ Ce qui fonctionne:

- [ ] Être TRÈS précis dans la demande
- [ ] Donner du contexte (TOUJOURS!)
- [ ] Spécifier le format de sortie souhaité
- [ ] Définir le ton et le style
- [ ] Donner des exemples si possible
- [ ] Itérer: tester, ajuster, retester

### ❌ À éviter:

- [ ] Prompts trop vagues ("écris quelque chose sur...")
- [ ] Oublier le contexte
- [ ] Ne pas spécifier la longueur
- [ ] Utiliser du jargon sans l'expliquer
- [ ] Accepter le premier résultat sans optimiser
