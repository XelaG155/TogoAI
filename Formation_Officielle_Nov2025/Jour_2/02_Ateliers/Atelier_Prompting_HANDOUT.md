## PARTIE 1: FONDAMENTAUX DU PROMPTING

### Structure d'un Prompt Efficace

**Formule:**
```
RÔLE + CONTEXTE + TÂCHE + FORMAT + CONTRAINTES = PROMPT EFFICACE
```

### Exemple de transformation:

#### PROMPT BASIQUE (inefficace):
```
Aide-moi avec le marketing
```

#### PROMPT EFFICACE:
```
Tu es un expert en marketing digital pour PME africaines.

CONTEXTE:
Je dirige une boutique de tissus wax au Grand Marché de Lomé. J'ai 3
employés et un budget marketing de 100,000 FCFA/mois. Ma clientèle est
principalement féminine, 25-45 ans, classe moyenne.

TÂCHE:
Crée un plan marketing sur 3 mois pour augmenter mes ventes de 30%.

FORMAT:
- Tableau avec: Action | Budget | Timing | Résultat attendu
- 5-7 actions maximum
- Prioriser actions à faible coût

CONTRAINTES:
- Budget total: 300,000 FCFA sur 3 mois
- Pas de compétences techniques dans l'équipe
- Tenir compte des fêtes togolaises
- Focus sur WhatsApp et réseaux sociaux gratuits
```

## PARTIE 4: CHECKLIST PROMPT EFFICACE

Avant de finaliser un prompt, vérifiez:

- [ ] **RÔLE** clairement défini
- [ ] **CONTEXTE** suffisant fourni (entreprise, secteur, situation)
- [ ] **TÂCHE** précise et sans ambiguïté
- [ ] **FORMAT** de sortie spécifié (tableau, bullet points, email...)
- [ ] **CONTRAINTES** importantes mentionnées (budget, délai, ton...)
- [ ] **TESTÉ** avec résultat satisfaisant
- [ ] **OPTIMISÉ** après premier test
- [ ] **DOCUMENTÉ** pour réutilisation
